# Project memory index

This is the **project-local** memory for physicsOS — committable notes that persist across sessions and agents. It is distinct from the harness's per-user auto-memory.

Use this for: durable physics context that belongs to the project, recurring conventions, the user's research interests, in-progress threads of investigation.

Do **not** use this for: anything that belongs in a paper note, an audit, or a claim file. Those have their own homes.

## Format

One short line per memory: `- [Title](file.md) — one-line hook`. Keep entries terse; the file itself holds detail.

## Entries

- [Conventions](conventions.md) — unit systems, metric signature, Fourier conventions used by default in this project.
- [Open threads](open-threads.md) — ongoing investigations not yet pinned to a single claim file.
