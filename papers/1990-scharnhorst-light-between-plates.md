# On propagation of light in the vacuum between plates

## One-line summary

Scharnhorst calculates a QED correction in the Casimir vacuum that changes the light velocity perpendicular to conducting plates.

## What it actually shows

- QED vacuum polarization in a parallel-plate Casimir configuration changes the effective propagation of light normal to the plates.
- The effect is tied to boundary conditions and the plate rest frame; it is not a freely portable Lorentz-invariant FTL device.
- The speed shift is a theoretical two-loop effective-action result, not an experimental demonstration of FTL signalling.
- Later causality analyses treat this as a constrained effective-medium/effective-metric example, not as arbitrary reciprocal tachyonic communication.
- A 2019 corrigendum corrected formula-level details, but not the broad status of the Scharnhorst effect as the canonical constrained example.

## Methods (briefly)

Two-loop QED effective-action calculation with Casimir boundary conditions on photon vacuum fluctuations.

## Key equations / results

The load-bearing result for this claim is qualitative: the Casimir boundary condition defines a special frame and direction for a tiny light-speed modification. The paper's exact numerical coefficient is not used in the current audit.

## Assumptions and regime of validity

- Parallel conducting plates.
- Low-energy QED effective-action approximation.
- Propagation normal to the plates.
- Boundary-condition-defined medium/rest frame.

## Caveats / open issues

This does not establish an operational, measurable, macroscopic, controllable FTL channel. It is a model where "faster than c" is mechanism-constrained.

## How it informs the mechanism-constrained FTL chronology claim

It supports the existence of a concrete theoretical class in which "faster than c" is not an unrestricted reciprocal sender-rest-frame rule. That is exactly the loophole the narrow chronology-safe claim tracks.
